# Profile Builder

A modern React application for creating and managing user profiles with dynamic form inputs, previewing, and local storage persistence. Built with React and Tailwind CSS.

## 🌐 Live Demo
Visit the live hosted app: [https://hashuse.github.io/profileBuilder/](https://hashuse.github.io/profileBuilder/)

## ✨ Features
- **Create Profiles**: Add personal details, bios, and links.
- **Dynamic Form Handling**: Validation and real-time state management.
- **Profile Management**: View, browse, and delete saved profiles.
- **Local Persistence**: Saves your data in `localStorage` so profiles remain across page reloads.
- **Responsive UI**: Styled with Tailwind CSS for seamless mobile and desktop experiences.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/HAshUse/profileBuilder.git
   cd profileBuilder
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
